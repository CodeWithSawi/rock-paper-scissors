# 🪨📄✂️ Rock Paper Scissors Game

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript. Challenge the computer, track your score, and enjoy a clean, responsive interface!

## 🎯 What You'll Build

Build a fully functional Rock Paper Scissors game where players can:

- Choose between Rock, Paper, or Scissors
- Play against a computer opponent with randomized choices
- See real-time results and score tracking
- Experience a responsive, visually appealing interface

## ✨ Features

- ✅ **Randomized Computer Results** - Computer makes unpredictable choices
- ✅ **Interactive Game Interface** - Click buttons to make your move
- ✅ **Real-time Score Tracking** - Wins, losses, and ties are automatically updated
- ✅ **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- ✅ **Visual Feedback** - See the result of each round instantly
- ✅ **Clean & Modern UI** - Polished design with smooth animations

## 🛠️ Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling, animations, and responsive design
- **JavaScript (ES6+)** - Game logic, event handling, and DOM manipulation

## 📚 What You'll Practice

| Skill                                   | Description                                                |
| --------------------------------------- | ---------------------------------------------------------- |
| 🖱️ **Handle user clicks**               | Capture and respond to button clicks                       |
| 🎯 **Select DOM elements**              | Use `document.querySelector()` and `getElementById()`      |
| 🔄 **Update page content**              | Dynamically change text and styles with JavaScript         |
| 🎲 **Generate random values**           | Use `Math.random()` for computer choices                   |
| 📊 **Process data with arrays**         | Store and manipulate game choices                          |
| ⚖️ **Control behavior with conditions** | Implement game logic with `if/else` or `switch` statements |
