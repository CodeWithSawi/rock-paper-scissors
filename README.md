# Rock Paper Scissors Game

A classic Rock Paper Scissors game built with HTML, CSS, and JavaScript. Challenge the computer, track your score, and enjoy a clean, responsive interface!

## Features

- **Randomized Computer Results** - Computer makes unpredictable choices
- **Interactive Game Interface** - Click buttons to make your move
- **Real-time Score Tracking** - Wins, losses, and ties are automatically updated
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Visual Feedback** - See the result of each round instantly
- **Clean & Modern UI** - Polished design with smooth animations

## Technologies Used

- **HTML5** - Structure and content
- **CSS3** - Styling, animations, and responsive design
- **JavaScript (ES6+)** - Game logic, event handling, and DOM manipulation
